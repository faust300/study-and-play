# study-and-play

Claude가 낸 알고리즘 문제를 Go로 직접 풀며 코딩 감각을 되찾는 저장소다. 콜백 재시도, 정산, 점검 시간대처럼 실무에서 만난 상황을 소재로 삼고, 문제를 하나씩 풀면서 Go 문법과 표준 라이브러리에 익숙해지는 게 목표다.

## 진행 방식

1. **출제** — Claude가 문제 설명, `// TODO`가 있는 함수, 채점용 테스트를 준비한다. Claude의 정답 풀이는 테스트 검증에만 사용한다.
2. **풀이** — 빈 함수를 직접 구현하고 `go test`로 결과를 확인한다.
3. **힌트** — 막히면 Claude에게 어느 지점에서 풀이가 어긋났는지, 다음에 무엇을 살펴보면 좋을지 묻는다.

## 문제 목록

| 문제 | 연습 내용 | 주요 Go 문법과 도구 | 상태 |
| --- | --- | --- | --- |
| [001 · 콜백 재시도](./001-callback-retry/) | 재시도 로그에서 미완료 작업 찾기 | `:=`, `range`, `_`, `map[int]bool`, `append` | 완료 |
| [002 · 맵과 슬라이스](./002-map-slice-drills/) | 개수 세기, 중복 제거, 그룹화, Two Sum, 순서 뒤집기 | `make`, `m[k]++`, `v, ok := m[k]`, 다중 반환, 값 교환 | 완료 |
| [003 · 정렬과 구조체](./003-sort-struct/) | 정산 순위 매기기, 상위 K개 찾기, 점검 시간대 병합 | 구조체, `sort.Slice`, 슬라이스 복사, `max`·`min` | 완료 |
| [004 · 파싱과 에러 처리](./004-parse-error-method/) | 콜백 로그 파싱, 재시도 대기열 구성, 결과 요약 | `strings`·`strconv`, 에러 반환과 래핑, `errors.Is`, 포인터 리시버 메서드 | 진행 전 |

## 테스트 실행

Go 1.23 이상에서 저장소 루트를 기준으로 실행한다.

| 용도 | 명령어 |
| --- | --- |
| 전체 문제 채점 | `go test ./...` |
| 002번 묶음의 테스트 결과 자세히 보기 | `go test -v ./002-map-slice-drills` |
| Two Sum만 채점 | `go test -v -run '^TestTwoSum$' ./002-map-slice-drills` |
| 콜백 로그 100만 건 벤치마크 | `go test -bench=. ./001-callback-retry` |
